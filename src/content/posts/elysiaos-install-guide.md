## 前言

[ElysiaOS](https://www.elysiaos.live/)是基于**Arch Linux**，**Hyprland** 魔改的操作系统，在安装前请确认您是否有对Linux使用的需求并且了解Linux的基本指令等基础知识。

本文将以当时安装环境情况作为参考，在实际实装时请根据具体情况进行调整。

## 安装前的准备

如果想安装好这个系统需要：**天时**，**地利**，**人和**缺一不可

### 地利

#### 硬件

一台已经装载了操作系统的电脑（我的电脑是荣耀的MagicBook16 Pro，操作系统是Windows 11）

一个用于作为启动盘的U盘（容量足够大即可，我的U盘是64G绰绰有余了）

一个畅通的网络（网线或WiFi都可）

一个可以让你查询ArchLinux wiki的另一台设备（手机电脑平板都可）

**（可选）**一个足够大的移动硬盘（因为我想装到移动硬盘里随插随用）

#### 软件

下载ElysiaOS的安装镜像（iso文件）

下载用于制作Linux启动盘的软件（我使用的是rufus）

一个浏览器可以用于访问[ArchLinux wiki](https://wiki.archlinux.org/)，wiki中可以设置中文或者去看中文wiki，但是请确认他还具有时效性，如果失去了时效性就去看原版。

### 人和

一颗愿意钻研的心：当你遇到问题的时候多查查资料，多问问ai，或者懂行的人。

巧用wiki：ArchLinux由于滚动更新的特性，大多数你需要的知识都在wiki中有较为详细的介绍。当你在阅读有关条目时可能会有大片的文字阅读，请静下心来仔细阅读与理解其中的含义。

### 天时

最后提天时是因为当你在安装的时候需要连接外网的一些网站来下载所需要的依赖包等，我是没找到在Live环境（就是启动盘的环境）下能有效加速网络的方式，我尝试过更换pacman的镜像没有明显提升速度，使用网络代理软件也没有成功代理。如果你有更好的解决方法欢迎一同探讨。

我当时能够安装成功纯粹是试的次数多了，那次正好网络还不错虽然缓慢但是还是全部下载成功了，于是安装才成功的，所以才叫天时。因此当你安装时遇到报错不要慌张，看看报的是什么错，大部分是网络连接导致的，如果是其他的自行去查血解决方案即可。

## 正式安装

### 进入Linux Live环境

确认你的启动盘已经安装无误，将你的启动盘连接电脑，重启电脑，然后一直按你能够进入BIOS界面的按键（我的是F2）。进入BIOS后**将安全启动关闭**，**将原来的Windows启动项关闭或者调整为USB最优先启动**（如果不明白我在说什么就去问问百度或者ai），然后保存并退出，等待电脑进入USB中的Live环境。

### 安装ElysiaOS

进入后桌面上有爱莉刻印的文件叫“Elysia Installer”（好像是这个名字，反正差不多），单机等待打开后在左上方有美国国旗样式的按钮，他是修改语言的，点击并选择中国国旗更换为汉语，然后根据引导进行操作。

\*在打开Install文件之前你可以按win键（Linux叫SPER键） + 空格键 呼出菜单，选择打开kitty（也就是终端），之后会默认给你下载插件，你可以主动按几次Ctrl+C取消安装，然后输入

```bash
pacman -Syy
```

来对库进行一个更新，顺便查看网络状况。

（此操作可以忽略）

### 安装成功进入系统

安装成功后会主动提示你点击reboot（重启）进入安装好的系统，点击后一路同意即可。

如果顺利的话过一会儿你就会进入安装好的系统了。

### 安装成功但是进入紧急模式

reboot后发现进入了一个没有图形化界面的纯dos页面，并且输出emergency mode字样的话，那么~~恭喜你~~大概率是成功安装了系统的，但是在系统的引导上面出了点小问题。（也可能是别的问题，我只遇到了这一种）此时输入你之前在安装OS时的密码来激活root权限，对系统进行修复操作。我当时是遇到了引导中对磁盘UUID书写错误导致的问题，手动修改引导项里的UUID重启后就解决了，这里不多赘述。

### 安装失败

查看报错信息与最后的输出日志，大概率是网络原因导致的，也有可能是efi引导的书写出现问题，我当时遇到了因为没删除之前的efi所以创建账户时冲突了导致的报错，我的解决办法就是手动将磁盘内的数据，分区等全部信息都删除（未格式化的那种状态）然后让Installer操作的。

关于磁盘中信息的删除：Live环境中内置了gparted，他是一个有图形化界面的磁盘操作软件，super+space打开菜单搜索后打开使用即可，记得保存与执行操作。

当然你也有可能遇到别的错误情况，届时请发挥你聪明的大脑与如今发达的网络来帮助你渡过难关。

### 你也不想你的爱莉系统像乐土一样昙花一现吧（笑）

我不知道别的Linux系统是否也是这样，至少我现在安装的这个是有这个情况的：当你在电脑开机的时候如果拔下了装载ElysiaOS的启动盘，那么~~恭喜你~~，你再插上去之后你的系统就找不到他的启动项了。不要问我为什么我会知道这种问题。但是系统还是在的所以可以补救，只是你要想修复启动项问题很麻烦，因此我们先提前让你将启动项配置好，避免出现如题的尴尬情况。

### GRUB

本系统使用GRUB作为引导加载程序，他默认是只有像我上面提到的，如果你的硬盘在常驻情况下他才能一直被系统读取引导。因此我们要对GRUB进行装入移动硬盘的一系列操作。[GRUB - ArchWiki - Arch Linux 百科](https://wiki.archlinux.org.cn/title/GRUB)

在百科中也提到了，当你要装入移动硬盘时要在安装GRUB中添加 –removable 选项，因此我们的具体操作如下：

```bash
# 1. 挂载分区（sdX为你实际装载启动引导EFI的磁盘，在终端中键入 lsblk 可以查看硬盘分区等信息）
mount /dev/sdX /boot/efi

# 2. 安装GRUB
grub-install --target=x86_64-efi --efi-directory=/boot/efi --bootloader-id=GRUB --removable --recheck

# 3. 生成GRUB配置
grub-mkconfig -o /boot/grub/grub.cfg

# 5. 验证安装
ls -la /boot/efi/EFI/BOOT/
```

**如果上述运行中报错了请自行增加（或删除）前面的 sudo**

### 我该如何知道我的GRUB配置是否成功了呢？

1. 如果/boot/efi/EFI/BOOT/目录存在，并且BOOT目录下有其他文件那大概率是成功了

2. 如果再次进入BIOS中看到USB的启动项中有了你的移动硬盘选项，那大概率是成功了

## 关于Windows与Arch Linux的双系统启动

### 1. 启用 os-prober

编辑GRUB配置文件：

```bash
sudo nano /etc/default/grub
```

在文件中添加或修改这一行：（大部分都是在文件最下面的几行里，被一个#注释掉了，删掉#即可）

```
GRUB_DISABLE_OS_PROBER=false
```

nano的基本操作：Ctrl+F可以查询，Ctrl+O保存，下方会出现文件路径，直接Enter回车保存即可，Ctrl+X退出

### 2. 确保已安装 os-prober

```bash
sudo pacman -S os-prober
```

### 3. 重新生成GRUB配置

```bash
sudo grub-mkconfig -o /boot/grub/grub.cfg
```

终端中出现Windows字样大概率是成功了

**\* 如果仍然不工作，可以尝试手动挂载Windows EFI分区**后重复上述操作

此时你的Windows启动项就可以被Linux的GRUB读取，这样你就可以在启动时选择启动哪一个系统了。

**\* 如果还不能选择，启动直接进入Windows系统的话，是因为你的启动项顺序是以Windows为售选择导致的**

此时重启电脑进入BIOS系统，在启动项中使用F5或F6来调整启动项的顺序，将ElysiaOS的启动项为首选择即可。

## 后记

之后就可以对你的ElysiaOS进行一些日常使用所需的配置了，比如安装一个浏览器，配置中文输入法等。

ElysiaOS内置了一个Floorp Browser 浏览器，不知道为什么我的电脑启动起来很慢，我在安装Chromium或者Edge都很流畅。

并且也内置了一个输入法fcitx5，你可以直接对它进行一些中文输入法相关的安装与配置。

而且他还内置了一个应用商店（名字忘记了，反正是什么shop）你可以通过它进行一些软件的下载。

总而言之对于一些人可能是第一次接触Linux系统，请尽量使用包管理器pacman或者其他管理AUR软件包的安装命令（如yay），尽量避免直接解压压缩包后直接点击启动软件的行为，Linux和Windows还是有不少差异的，随意的使用难免未来会出现什么问题。
